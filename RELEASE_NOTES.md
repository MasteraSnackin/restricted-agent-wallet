# Restricted Agent Wallet - LocalNet MVP

This private release packages the Cantor8 D1 Restricted Agent Wallet source and
its final two-minute ElevenLabs-narrated demonstration video.

Included:

- production `TokenMandate` Daml package against stable Canton Token Standard
  V1 interfaces;
- separate deterministic test package with 59 successful test-ledger
  transactions;
- least-privilege LocalNet adapter and loopback judge console;
- Python boundary and idempotency tests;
- three pinned Splice 0.6.8 interface DARs with provenance and Apache-2.0 licence;
- dated LocalNet smoke evidence and judging notes; and
- `Restricted-Agent-Wallet-2-Minute-Demo-ElevenLabs.mp4` as the release asset.

Verified boundary: Daml SDK 3.4.10, Java 21 and loopback-only Splice 0.6.8
LocalNet using Amulet. Cantor8 DevNet, production deployment, production
credentials, LLM integration, MCP integration and autonomous planning remain
unverified and are not claimed.

The project code arrived without a public licence. This repository therefore
remains private and grants no inferred public reuse licence.
